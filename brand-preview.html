Rebuilt lockup: brand-red bar + heavy black plus, with the tight Hays+Sons wordmark. Same artwork on every surface — app, generated PDF packet, favicon and desktop icon.

1 — The mark

The bar and the plus are exactly the same height and share one stroke width. The plus crossbar runs flush into the bar — no gap — so bar + crossbar + stem also read as an "H", while stem + crossbar read as a "+".

Notes
Deliberate call: the plus and the wordmark share one near-black (#1A1A1A) so the mark locks up as a single unit, rather than the plus being UI slate and the text being brand ink.
Typeface: no webfont is loaded, so the wordmark renders in the system sans and varies slightly by OS. The supplied artwork uses a geometric face — if a licensed web font is added later it only needs swapping in BrandLogo.tsx and the PDF font embed.
Icons: the raster icons carry a white field because the plus is near-black — transparent, it would disappear on a dark wallpaper or taskbar and the mark would read as a lone red bar. The in-app mark and the SVG favicon stay transparent, faithful to the artwork.
